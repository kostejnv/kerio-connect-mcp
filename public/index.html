ChatGPT or Claude can search and read your Kerio Connect mail

This server connects AI assistants to a Kerio Connect mailbox through the Model Context Protocol (MCP). Everyone signs in with their own Kerio account. The assistant can then find e-mails across the whole history, read them in full, read attachments and give you download links. Access is read-only by default.

02Connecting takes a minute

Add this address to your assistant as a custom connector:

%MCP_URL%
assistantwhere
Claude (web, desktop)Settings → Connectors → Add custom connector → paste the address.
ChatGPTSettings → Apps & Connectors → Developer mode → Create → paste the address, authentication OAuth. In a workspace an admin adds it once; everyone then connects with their own account.
Claude Codeclaude mcp add --transport http --scope user kerio %MCP_URL%, then /mcp → kerio → Authenticate.

A sign-in page opens: enter your Kerio server (for example mail.example.com), your username and your password. Use your normal account, not an administrator account.

03What the assistant can do

toolwhat it does
mail_folders_listLists your mail folders and which one is the inbox, sent items, drafts, deleted items or junk.
mail_searchSearches all mail or one folder by text, sender, recipient, subject, date or unread, newest first and across the whole history. Every result says whether it is incoming or outgoing.
mail_getReads one e-mail in full, with its list of attachments.
mail_get_attachmentReads an attachment: text from PDF, Word, Excel, CSV and text files; images as images.
mail_attachment_linkGives download links for attachments in their original format, one per file and one ZIP for all. Links work for 10 minutes.
mail_sendSends a plain-text e-mail. Only when this server allows sending and you ticked “Allow sending e-mails” when signing in.

04Your password and your mail stay yours

nothing is storedYour password is only kept encrypted inside the key your assistant holds. The server has no database and no files with your data.
reading changes nothingMessages are not marked as read, moved, flagged or deleted.
sending needs two yesesThe server must allow it and you must tick it at sign-in. The assistant cannot switch it on, and it never sends a message twice on its own.
mail is untrustedThe assistant is told to treat e-mails and attachments as data and never to follow instructions written in them.
signing outRemove the connector in your assistant. Without use, the key expires after 90 days.

ChatGPT nebo Claude prohledá a přečte vaši poštu v Kerio Connect

Tento server propojuje AI asistenty se schránkou Kerio Connect přes Model Context Protocol (MCP). Každý se přihlásí svým vlastním účtem v Keriu. Asistent pak umí najít e-maily v celé historii, přečíst je celé, přečíst přílohy a dát vám odkazy ke stažení. Přístup je ve výchozím stavu jen pro čtení.

02Připojení zabere minutu

Tuto adresu přidejte do svého asistenta jako vlastní connector:

%MCP_URL%
asistentkde
Claude (web, aplikace)Nastavení → Konektory → Přidat vlastní konektor → vložit adresu.
ChatGPTNastavení → Aplikace a konektory → Režim pro vývojáře → Vytvořit → vložit adresu, ověření OAuth. Ve workspace ho správce přidá jednou; každý se pak připojí svým účtem.
Claude Codeclaude mcp add --transport http --scope user kerio %MCP_URL%, potom /mcp → kerio → Authenticate.

Otevře se přihlašovací stránka: zadejte svůj Kerio server (například mail.firma.cz), uživatelské jméno a heslo. Použijte svůj běžný účet, ne účet správce.

03Co asistent umí

nástrojco dělá
mail_folders_listVypíše vaše poštovní složky a pozná, která je doručená, odeslaná pošta, koncepty, koš nebo nevyžádaná pošta.
mail_searchHledá v celé poště nebo v jedné složce podle textu, odesílatele, příjemce, předmětu, data nebo nepřečtených, od nejnovějších a v celé historii. U každého výsledku řekne, jestli je příchozí, nebo odchozí.
mail_getPřečte jeden e-mail celý, se seznamem příloh.
mail_get_attachmentPřečte přílohu: text z PDF, Wordu, Excelu, CSV a textových souborů; obrázky jako obrázky.
mail_attachment_linkDá odkazy ke stažení příloh v původním formátu, na každý soubor zvlášť a jeden ZIP se všemi. Odkazy platí 10 minut.
mail_sendOdešle e-mail jako prostý text. Jen pokud server odesílání povoluje a vy jste při přihlášení zaškrtli „Povolit odesílání e-mailů“.

04Vaše heslo i pošta zůstávají vaše

nic se neukládáHeslo je jen zašifrované v klíči, který drží váš asistent. Server nemá žádnou databázi ani soubory s vašimi údaji.
čtení nic neměníZprávy se neoznačí jako přečtené, nepřesunou, neoznačí příznakem ani nesmažou.
odesílání chce dvě anoMusí ho povolit server a vy ho musíte zaškrtnout při přihlášení. Asistent si ho sám zapnout nemůže a nikdy sám neodešle zprávu dvakrát.
pošta je nedůvěryhodnáAsistent má pokyn brát e-maily a přílohy jako data a nikdy neplnit pokyny, které jsou v nich napsané.
odhlášeníOdeberte connector ve svém asistentovi. Bez používání klíč po 90 dnech vyprší.
